# Pocket Notes — fictional mock charter

Revision: 1.0
Owner: Avery Example (fictional)
Maintainer: Quinn Example (fictional)

**Simulation only. No event in this example authorizes real work or publication.**

Purpose: demonstrate a small notes-export change with traceable decisions and exact-candidate evidence.

The owner adopts the charter, approves scope, accepts the exact candidate, and authorizes its publication destination. The maintainer may implement and run local checks within an approved scope. An assistant may report results but cannot manufacture owner approval.

The ledger is append-only. Corrections preserve original entries. Working context summarizes the ledger and grants no authority.

Required checks are named in the approved scope. FAIL remains visible. Changed artifacts require a new candidate. Candidate acceptance requires all required checks to PASS, and release requires owner acceptance plus exact-candidate publication authorization.

CSV export remains outside this scope. Do not count deferred work as completed. Release evidence must identify the actual destination and recovery procedure.

All names, decisions, notes, locations, and publication receipts here are fictional. Local test results are reproducible, but the public release is simulated.
