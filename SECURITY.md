# Security

Do not post tokens, private ledger content, or personal information in a public issue. Use a repository owner's private security reporting channel once configured. This starter does not ship a private reporting address.

The validator must never execute commands from evidence or follow files outside the selected project root. Report parser crashes, path escapes, or acceptance/release prerequisite bypasses with a minimal synthetic reproducer.

Version 0.1.0 is a starter and has not received an independent security audit. Avoid running checks with privileged credentials against untrusted repositories.
